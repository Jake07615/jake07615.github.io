Install

  1. Get Homestead from Modrinth or CurseForge, and import it into the matching app as a new instance.
  2. Give the instance 6 to 8 GB of memory. More than about 10 GB can make it run worse.
  3. Launch it once, then add the server address above in Multiplayer. The modpack is Java Edition only.
